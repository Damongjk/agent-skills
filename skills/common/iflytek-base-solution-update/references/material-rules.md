# 货架素材映射与保护

整合旧 ifeishu-base-ops 与货架历史版本的业务规则；字段类型以本次 list_fields 返回为准。

| 材料目录/类型 | 通常对应字段 |
| --- | --- |
| 01 售前PPT | 产品/方案：售前PPT；服务：服务介绍PPT |
| 02 彩页/宣传彩页 | 产品彩页 / 宣传彩页 |
| 03 宣传视频、产品视频、演示视频 | 音视频 |
| 04 演示环境及补充材料 | 更多材料，按实际内容与字段约定 |
| 05 报价 | 产品报价 / 报价 |
| 功能清单、控标参数、建设方案、白皮书、手册、POC 报告 | 对应同名或语义相符的实际字段 |
| 07 硬件/算力配置 | 硬件配置 |

普通文档材料默认填具体文件的真实分享链接，不填目录代替文件。历史已确认的例外：产品“音视频”URL 字段用视频集合文件夹，形如 `{"link":"已确认的文件夹URL","text":"产品名音视频"}`；方案音视频历史是文本字段，放集合文件夹链接。例外须先确认当前字段类型及业务约定，不扩展成“所有材料都用文件夹”。

Text 类型多文件用换行分隔；URL 类型按当前结构用 link/text 对象；其他类型不要套用文本格式。只看到文件名时可能是链接渲染值，不能推断 URL、重写显示文本或误报链接缺失。需要修正时从真实目标取得新 URL，保护现有链接。

无材料时新增记录留空，更新时不发送该字段以保留原有值。空文件夹不填占位链接。产品图等附件按当前平台限制由 Web UI 上传，普通 Drive 文件 token 不可直接充当 Base 附件。
