# 星火国际货架维护

平台操作仅走 ifeishu MCP。链接先 inspect，首次批量操作先 conventions。可从本机 `~/.cc-switch/local-context/ifeishu-resources.json` 的 shelf 部分读取已知 Base、表和素材入口；没有本机索引时由用户提供真实链接，不能猜地址。

## 录入与更新

1. 用 app 确认当前表，table_id + list_fields=True 读取字段名、类型及只读字段。旧表数、字段数和选项是历史快照，不替代查询。
2. 分页读已有记录，按名称和上下文确认目标，避免重复新增；记录 ID 用实际查询结果。
3. 素材优先用户已给链接、经 inspect 确认的目标或 MCP 返回的真实 URL。快捷方式 token 不等于目标文档 token，不拼接未经验证的地址。
4. 当前 `ifeishu_drive` 没有目录枚举动作。需要逐层扫描时报告该缺口，请用户提供素材链接，或单独维护 MCP 增加能力；不经 shell、lark_client 或 API 直连绕行。
5. 按 [字段与素材规则](references/material-rules.md) 组装值，只写本次目标字段。简介从材料归纳，材料不足留空；不推断报价、负责人或缺失能力。
6. base_write 使用批量端点，每批最多 500 条；检查每项状态，部分成功不回滚。不确定是否写成时先查询现状；回读核对目标字段、日志和未改数据。

## 保护规则

- 已有材料显示成文件名，不代表底层没有链接。先核对实际值/界面，不能把渲染文本当“缺链接”而覆盖；多文件粘连也不能直接把显示文本回写。
- 产品等级、海外适配、部署区域和跨表关联按用户既有约定人工维护，除非本次明确授权调整。人员 ID 从当前 Base 命名空间取，Lookup 等只读字段不写。
- 不删除任何货架 Drive 文件。本技能的记录维护不授权清理云端文件；用户另提删除需求时作为独立任务处理。
- 新增或变更可按当前更新日志表与用户约定记录，避免重复日志；是否发额外消息需用户明确授权，不把日志里的标志位视为外发许可。

## 货架校验

可在现有 MCP 能力范围内检查重复值、占位链接和记录对应关系，输出报告。名字不同不等于缺记录；链接未出现在某次枚举结果不等于失效。“疑似”项先核实，再按已授权目标更新，不批量猜改。

原 shelf_check.py 依赖直接调用底层 CLI，已退出活动技能并保留本地备份。当前技能不含自动创建定时任务或默认修复数据的步骤；需要定时校验由用户另行设置，执行时仍遵循 MCP 能力边界。
