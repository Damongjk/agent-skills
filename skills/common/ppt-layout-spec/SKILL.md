# PPT 设计与验收规范

以 [规则集](references/ppt-layout-rules.md) 为唯一个人规范。Codex、WorkBuddy 和 AStudio 均使用本入口，不依赖某一客户端专属工具。

## 两个检查点

1. 设计或重排前，读取规则集顶部“设计前速查”，把相关条目转成当前页约束；争议或细节再查对应正文。
2. 交付前，结合文件结构和成品渲染逐项检查，标记 PASS / FAIL / MANUAL；修正失败项，并明确仍未验证的部分。只有图片输入时只能做视觉检查，不能声称已读 XML。

仅审查既有 Deck 时直接执行第二个检查点。使用当前环境已有的 Office/演示文稿工具，或解析 PPTX；不要求安装客户端专属编辑器。

## 个人默认与任务边界

- 默认白色/浅灰背景，用户明确要求时才用深色。对外材料默认英文单语；中文或双语按明确要求执行。
- 继承品牌母版、配色与风格；按内容设计新页。复杂架构、流程、拓扑保留关系和构图，仅美化；普通内容页可以重排。
- 字体族不超过两种；字号层级一致，优先保证可读性；图标用矢量/图片，不用字符图标或 emoji。
- 仅排版优化时原文逐字保留。需要改文案则列出具体建议并取得授权；新建、翻译或已授权的内容改写不受“原文子集”限制，但不得编造事实。
- 重排指定页默认交付独立 PPTX 和渲染图；用户要求完整 Deck 或备份后原位修改时遵从。不要因为默认交付形式删掉未指定的页面。

## 自动检查的解释

检查时记录页码、对象、证据与修复建议；XML 信号是候选问题，不能代替视觉判断。

| 检查 | 正确解释 |
| --- | --- |
| 文本内边距 | 对齐类文本框可归零；卡片、引文等容器保留留白。0.1 英寸 = 91440 EMU；读取实际四边值，不假设默认全部相同 |
| 圆角矩形 | python-pptx `adjustments[0]=0.08` 对应 OOXML `fmla="val 8000"`。整数与小数不能直接比较；药丸/圆形和图片圆角不按普通 roundRect 修正 |
| 换行与 autofit | 短标题/标签按规则管理换行；正文保留需要的换行。识别缩字、溢出、裁切，不能一刀切调整所有框 |
| 字体/颜色 | 检查继承样式、实际字号与字体替换；字体数量和对比度异常应结合角色、图片背景复核 |
| 内容与图表 | 对齐、信息密度、单页观点、图表强调及复杂关系语义都需成品检查；不能只凭标题里有“和”就判失败 |

规则详情与检查清单均在参考文件。不要自动恢复旧 Windows COM 脚本为跨平台必跑条件。
