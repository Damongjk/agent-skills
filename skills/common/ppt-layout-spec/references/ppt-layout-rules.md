# PPT 制作规范 · 规则集

本文件是 `ppt-layout-spec` 的唯一个人规范来源。保留 L / T / Co / V / D / N / C / M 编号，便于设计与验收引用。规范同时覆盖内容论证、全局版式、对象制作和可编辑交付。

## 适用与优先级

- 优先级：用户当前明确指令 > 用户指定的已批准定稿/品牌模板 > 本规则的个人默认 > 工具或通用设计默认。任务已明确时直接执行；只有缺失信息会实质改变结果时才澄清。
- 先判定输入角色：必须保留的定稿、仅供取内容的素材、视觉参考。仅给内容素材不代表授权复制其风格；仅要求分析不代表授权改文件。
- 指定定稿的固定元素与参数应继承。普通参考只作借鉴；不能以“参考稿可能保守”为由擅自放大字号、移动标题或重写文案。
- 有项目资料时，同时读取任务相关的本地材料和关联云文档正文。版本/事实冲突需核对；样式定稿不能替代事实核验，链接清单不能代替正文。
- 从样本提炼习惯时，区分稳定重复规律、内容所需的特殊页和残留问题。单个小字号、旧页码、重复文案、相邻色值或未组合对象不自动成为规范。
- 默认浅色内容页；已批准的深色封面、章节页或结束页可以保留。新建对外材料未指定语言时默认英文单语，内部材料默认中文；已有稿沿用已批准语言，不借排版任务自动翻译。

## 设计前速查

按当前任务选适用项，形成简洁工作约束；不要求为每次任务额外交付规范报告。

| 维度 | 开始制作前必须确定的约束 |
| --- | --- |
| 范围 M2 / N3 | 受众、场景、主线、允许变更范围与输出格式；读完整稿后再做局部视觉 |
| 母版 L3 / C5 | 幻灯片到版式/母版的关系；必须继承的占位符、Logo、背景、装饰和页脚 |
| 栅格 C1 / L4 | 页面尺寸、参考线、标题/说明/主体边界、列宽、列间距和安全区 |
| 对齐 L1 / L5 | 页边界、容器、同级文字、图标/连接点、跨页位置；顶边、基线或中心的选择 |
| 文字 L2 / T1–T3 | 有效字体、字级、字重、语义断行、自动换行与尺寸模式 |
| 图形 C3 / V1–V2 | 复杂关系的方向与层级；组件编辑结构；同类圆角的视觉尺度 |
| 视觉 Co1–Co3 / C4 / D1–D3 | 主次色、分类色、描边/渐变/阴影、内容饱满度和主要视觉焦点 |

## 版式与栅格（L）

### L1 对齐文字，显式管理内边距

- 对齐类文本框优先将四边内边距归零，使框边界接近文字排版边界。缩进、制表位、段落和标点仍会影响可见起点，需看成品。
- 卡片/标签需要留白：形文一体时保留内边距；背景与文字分离时可通过对象偏移建立留白，不叠加无意缩进。
- 验收：读取四边实际值，检查同级文字的可见起点；不要把“框齐字不齐”判通过，也不要把必要留白清零。0.1 英寸 = 91440 EMU。

### L2 按内容形态管理换行与尺寸

- 单行标题、KPI、标签优先关闭自动换行；按已批准模板使用“根据文字调整形状”等合适模式，检查增长后的形状是否侵入安全区。
- 连续正文可自动换行；固定多行短句可关闭自动换行并保留语义分行。不能把所有正文切到同一模式。
- 避免靠自动缩字容纳超量内容。先调整允许变化的版面；删文、拆页或改写须符合授权范围。
- 验收：检查实际渲染的折行、裁切、溢出和字号变化。自动适配占位符的标称宽度不能独立证明溢出；关闭换行也不能保证字体替换后仍能放下。

### L3 母版负责固定框架，版式负责占位符

- 先读取母版（Slide Master）、版式（Layout）和占位符（Placeholder），再编辑页面。模板已有的标题、分类导航、说明、页脚和页码使用对应占位符；Logo、背景、品牌线等图形保持原有继承。
- 页面承担该页特有的主体内容，不逐页重绘等价页眉，不叠加第二套Logo、背景或页码。
- 允许有依据的局部尺寸覆盖，如标题随文字增长；保持已批准的起点、字级、基线和安全区。不仅因有局部覆盖就重置格式。
- 验收：检查继承关系、重复元素和翻页稳定性；不为“精简母版”擅自删除未使用版式、引用资源或特殊页版式。

### L4 用间距表达归属，主体服从安全边界

- 相关元素距离体现归属；组件内外间距形成清楚层级。文字避开容器边缘，主体避开Logo、页脚和品牌装饰。
- 同类构图复用列宽、行高和间距；三列、四列、非等宽图文可各有参数，不强制全篇一种列数。
- 验收：并列内容是否有可比较的空间；留白是否服务分组和阅读。边距按模板校准，不套用所有页面至少1厘米的固定阈值。

### L5 五层对齐：边界、容器、文字、图形、跨页

- 依次检查整页边界；同类容器尺寸与分布；模块内标题/说明/指标的对应位置；图标可见尺寸与连线连接点；同类页面之间的位置。
- 按角色选择对齐方式：多行正文常以顶边对齐；行内标签或不同高度的短标题可按中心/基线对齐。框顶边不一致不必然是问题。
- 引号、符号和带透明边缘的图片可做小幅光学补偿；依据实际可见内容，不以“光学对齐”掩盖明显漂移。
- 验收：重复卡片的标题、解释、数字、分隔线、日期等逐层对应，不能只检查最外层矩形。

## 字体与层级（T）

### T1 先锁定同级字级，再在约束内保证可读

- 从已批准模板提取主标题、说明、模块标题、正文、标签、注释、KPI的字级与字重。同级跨页一致，正文按角色使用有规律的层级。
- 在版面和层级允许范围内提高可读性；不为“字号最大化”擅自改变定稿比例，也不统一缩字来塞内容。
- 获得内容调整授权时才删改文字或改变页数；否则先解决布局，并指出仍需决策的容量问题。
- 验收：按最终屏幕/投影用途查看成品，辅助小标签与核心信息分开判断；样本中的小字不成为所有场景的可读下限。

### T2 语言和辅助英文服从受众

- 遵守已批准语言；新建未指定语言时使用“适用与优先级”中的默认。双语按明确需求执行，不自动逐句中英重复。
- 分类导航、术语英文与完整双语正文是不同角色。主次字号、字重和位置按作用确定，不把所有英文排成同级副标题。
- 验收：核心信息能否通过主要语言独立理解；辅助英文是否抢占空间或因过小而失去作用。

### T3 字体族收敛并正确解析继承

- 默认控制在两种字体族以内，以字重建立层级；服从品牌或文字系统的必要要求，避免逐页混入字体。
- 解析主题、母版、版式、图表与文本运行样式；合并字体的中英文别名，如“微软雅黑”与“Microsoft YaHei”。备注主题、未使用资源与真正显示的第三种字体应区分。
- 验收：检查字体缺失/替换和实际显示；不只统计XML中的不同字符串就判不一致。

## 配色与对比（Co）

### Co1 品牌色收敛，强调与分类分开

- 用有限品牌主色和中性色建立整体风格，明确主要视觉焦点。渐变/实色强调用于重要结果、推荐、协同主体或能力，不固定放在最后一列。
- 多场景、多系列或阶段可用分类色；并列证据可共同强调。不能以颜色种数或强调对象数量直接判失败。
- 验收：主次是否清楚、分类是否必要、重点是否竞争；同类组件复用颜色角色。

### Co2 关键文字与实际背景有足够对比

- 浅底深字、深底浅字；必要时为叠图文字设置底板。正文4.5:1、大字3:1可作对比度检查参考，需结合字体尺寸、透明度、渐变与放映环境。
- 验收：数字、图表标签和说明在实际背景上能否读清；不只计算名义填充色而忽略叠图/透明效果。

### Co3 语义色在相应范围内稳定

- 正负、风险、对照组等明确语义保持一致；同一比较序列跨页不得换色或反转涨跌含义。
- 品牌蓝不必在全篇只代表一个业务对象；局部分类色应在该分类范围内稳定，与图例相符。
- 验收：颜色变化是否使读者误认对象或结果。保留定稿固定品牌色，新增对象用已确认色板；已授权统一配色时可在范围内整理相邻色值，无需逐项确认。

## 一致性（C）

### C1 统一参考线和页面边界

- 读取实际尺寸及母版/版式/演示文稿层的参考线，记录标题、说明、主体、安全区和常见列网格。仅有截图时可测量推断，但须标为推断。
- 检查对象是否落实到边界。保存参考线不等于已经对齐；没有显式列参考线也不代表没有列网格。
- 常规页保持稳定外框；封面、视频、附录、阶梯路线等可按功能有明确例外，不为统一边界损害图形或解释空间。
- 验收：逐页与跨页对照，计算时处理组合缩放和坐标变换。`p15:guide`使用master unit（1/576英寸），形状常用EMU，不可混用。

### C2 参考稿的使用方式由任务决定

- 用户指定手动定稿为基准时，继承其固定项和重复组件参数；新内容在这些边界内设计。
- 普通视觉参考可借鉴配色、图形语言和层级，再校准字号与密度；内容素材不自动成为风格模板。
- 验收：不以通用美化默认覆盖已批准参数，不把样本偶然误差当偏好。[量化参考配置](reference-profile.md)仅在适用时读取。

### C3 复杂图保留构图语义

- 既有架构、流程、拓扑和闭环的相对层级、连接方向、分组、回流与堆叠关系应保留，只在授权范围内调整视觉。
- 普通对比、并列要点和图文说明可按任务重排；重构复杂图需有相应授权，并逐条核对业务关系。
- 验收：输入、处理、输出、数据/控制流和归属是否保持；不能把有意义的结构拆成无连接卡片。

### C4 同类组件统一视觉语言

- 同类卡片、标签、图标与截图复用描边、阴影、渐变及图片处理；不同角色可有明确差别，如普通卡片无阴影、重点截图有轻阴影。
- 圆角遵循V2，图标遵循V5。主题色板与对象直接设色分别识别，不能因主题名为Office就用默认颜色替代现稿品牌色。
- 验收：同类组件并排/跨页比较，避免来源不同造成风格跳变；不强制所有对象拥有相同效果参数。

### C5 继承母版体系，按内容选择正文构图

- 保留模板的母版、版式占位符、固定品牌元素和字级。PowerPoint“版式”是继承结构，“正文构图”是每页的信息安排，两者不能混淆。
- 为流程、架构、前后对照、矩阵、图文、时间线或数据选择能解释关系的构图；不把全篇改成卡片，也不拆掉合理并列结构。
- 验收：固定框架稳定，主体构图与页面问题匹配；已有内容适合的构图可以复用。

## 图文与图表（V）

### V1 对象结构服务编辑与对齐

- 简单标签、按钮和流程节点优先形文一体；多层级卡片允许背景、标题、正文、分隔线和指标分开，按移动/复制用途组合。跨组连接按需要保留独立性。
- 保持文字与图形原生可编辑，组件可安全移动；不为形式统一拆散合理组合，不把所有内容合并成图片。
- 验收：能否单独改字、整体复制/移动且关系不丢；不按“文字是否嵌在背景形状中”单项判通过。

### V2 圆角按实际视觉尺度统一

- 优先遵循当前风格中同类组件的可见圆角半径；尺寸不同可使用不同圆角比例。新建同类卡片可从相近实际半径起步，再视觉校准。
- 普通 `roundRect` 的圆角半径约为短边 × 归一化adj；OOXML `val 8000` 对应0.08。指定半径r时，`adj = r / min(width, height)`，再换算为OOXML整数；组合缩放需计入最终尺寸。
- 不把0.08、固定毫米数或其他单一参数用于所有形状。药丸、圆形、强调条、图片裁切与特殊几何按角色处理。
- 验收：同类圆角的视觉重量一致且不侵占文字；比例不同本身不构成失败。

### V3 图表支持结论，保留必要比较

- 有充分证据时用结论表达发现；页面标题已给结论时，子图可用指标名称。保留比较需要的系列、基准、时期、单位与标签。
- 主要注意力给关键差异、时期或趋势；可以强调一个区间、多个对应指标或一组系列，不强制只突出单个数据点。
- 验收：比较对象与结论依据清楚；强调不造成基期、量级、分母或统计范围的误读。

### V4 数据对象可编辑，减少图表噪音

- 数据图优先原生图表并保留数据；责任矩阵等优先原生表格。表达复杂关系可用原生形状排布矩阵，文字与结构仍可修改。
- 不用Excel截图或生成图片替代应可编辑的数据证据。仅有原始截图时可保留并说明限制，不猜数重建；产品界面截图不属于必须重绘的表格。
- 去掉无意义的3D、冗余网格、图例和装饰，保留读数及比较所需元素。
- 验收：对象类型、嵌入数据/工作簿与关系有效；看似正确的渲染图不等于数据可编辑。

### V5 图标统一可见尺寸与风格

- 使用SVG/PNG图标或原生图形，统一线性/填充、颜色和视觉重量。不用emoji、符号字体或键入字符代替功能图标；正常标点与标准项目符号不属于此禁用范围。
- 比较可见轮廓，不只比较含透明留白的图片外框；保持纵横比，按可见内容校准。
- 验收：尺寸、粗细、颜色、中心与相邻文字协调，字体变化不会使图标失效。

### V6 图片、截图和视频承担解释或证据作用

- 视觉回答业务痛点、机制、场景、架构、流程或价值问题；截图与讲解对应明确功能，避免无关装饰占主体。
- 区分概念示意、Demo、模拟结果和真实业务结果。产品界面的示例数字不自动成为案例证据。
- 保留比例、必要裁切、清晰度、视频及海报图关系；静态预览正常不能证明媒体可播放。
- 验收：是否帮助理解页面问题、界面是否可辨、媒体状态是否与实际验证一致。

## 信息密度（D）

### D1 内容合理占据主体，保留有功能的留白

- 按讲解任务分配空间，避免内容缩在角落或无内容色块占主体。留白用于分组、主次、节奏和呼吸，不机械铺满。
- 内容少时先调整图文尺度与关系；不能为填空自行补口号、复制文案或添加无意义卡片。
- 验收：阅读顺序清楚、空间与重要性相符；封面、章节、结束页按其用途判断。

### D2 主体在统一安全区内收束

- 常规主体上下沿接近当前模板的内容边界，底部品牌与页脚保留安全空间。不使用“空带不得超过1厘米”等跨模板硬阈值。
- 密集附录、视频或特殊流程可有明确例外；不为贴下边界拉伸截图、增高空卡片或压缩说明。
- 验收：依据C1实际边界检查跨页稳定性及碰撞、失衡空洞、贴边问题。

### D3 强调有用途，结论带按需使用

- 色带、徽章、引号、顶部细条和结论带须承担导航、分类、关系、证据或总结作用，纯装饰保持克制。
- 主要视觉焦点清楚，允许必要次级强调。不机械限制“装饰最多两处”，也不将每种模板装饰复制到每页。
- 验收：去掉该元素是否损失信息或品牌框架；总结带是否重复标题/说明、是否含未经授权的新文案。

## 叙事与结构（N）

### N1 标题形式服从页面任务

- 观点、结果与比较页优先有依据的判断；架构、案例介绍、演示、方法说明和附录可用主题标题。保留已经清楚的批准标题。
- 标题说主要要点，说明补充范围/条件，主体解释或举证，避免逐句重复。长度与行数服从模板，不以是否含动词单项判失败。
- 验收：只看标题能否知道本页回答什么，结论是否有依据；标题规则不构成擅自改文案的授权。

### N2 一页围绕一个客户问题

- 同一问题可有多个必要维度，如输入—处理—输出、双方分工或多种场景。出现“和/与/且”不构成拆页理由。
- 只有多个独立问题争夺注意力、无法在既定层级内解释时才考虑拆分；改变页数须符合任务范围。
- 验收：所有模块能否共同回答本页问题，是否有无关并列话题。

### N3 故事线逐步建立理解与决策依据

- 编辑前先读完整稿，理解每页作用与承接。解决方案可按客户问题、整体方案、机制/差异、落地条件、证据和下一步组织；这是决策逻辑，不是固定章节数量和顺序。
- 先用业务语言解释需求与变化，再引入必要技术；详细机制可放附录。案例包含范围、实施过程、双方工作与结果依据。
- 验收：抽读标题及必要说明是否形成连续主线；重复页面是否增加信息；结束动作是否具体可执行。

### N4 价值、投入和证据边界清楚

- 关键能力交代输入、处理、输出和必要条件；审批、接口、数据、权限、渠道产能、运营参与等依赖按实际表达，不编造已实现能力。
- 区分建议路线与历史周期、PoC目标与验证结果、总体价值与单项指标。不同语境的数字不为形式统一改成一样。
- 核对指标时期、对象、去重方式、分母、单位与来源；百分比增长与百分点变化分开。不凭算术关系推导漏斗，不把同比/回测描述自动归因为AI增量贡献。
- 验收：以同客群、同周期、同口径等可比条件解释价值；保留来源与备注。口径未确认时明确边界，不用更强措辞掩盖缺口。

### N5 同级模块的角色、依据与产出对应

- 并列卡片先明确各自回答的问题，再配置说明、依据与产出；避免只改标题其余复制，或把一个模块的依据放到另一个模块。
- 如“产品—权益—话术”分别表达产品匹配、参与激励和沟通表达；整包审核/发布属于共同条件，可放公共区域，避免每卡重复。
- 验收：每张卡读成“针对什么—依据什么—输出什么”时逻辑闭合；共用条件归属清楚。仅排版发现问题先建议，不擅自改字。

## 交付与验证（M）

### M1 优先可编辑主文件，交付范围遵从任务

- 指定页重排默认交付独立可编辑PPTX供回看/合并；要求完整Deck或原位修改时按其要求执行，保留范围内其余页面。授权原位改写前准备可恢复副本，不在项目堆积长期备份。
- 成品渲染用于检查，默认放临时目录；用户要求或确有展示必要时才交付预览。不自动生成PDF、全篇总览图或重复格式。
- 在 macOS 调用本机 PowerPoint 校验时，将副本和导出文件放在固定文件夹 `~/Documents/Codex/PowerPoint校验/`，用唯一文件名区分并行任务。将副本的绝对路径传给 `/usr/bin/open -g -b com.microsoft.Powerpoint "$pptx"`。这与 Finder 打开文稿使用同一系统机制。复用旧脚本时也要替换 PowerPoint 内部的 `open (POSIX file …)` 步骤，这种打开方式可能对每个新文件单独请求授权。
- 等副本出现在 PowerPoint 的演示文稿列表中，按文件名定位并核对完整路径，再检查、导出或关闭该副本。涉及外部链接时，保留相对路径，按验证目的核对链接指向的实际文件。完成后只将本次临时文件移入废纸篓，保留固定目录供下次复用。
- 文案建议只交付文本，审查只交付发现；不因使用本技能自动创建/上传云文档或改原PPT。
- 验收：主格式、页数、范围和编辑能力符合请求；不遗留无用过程文件。已明确替代的旧版按用户的可恢复回收规范处理，不永久删除。

### M2 排版与文案的授权边界

- 仅排版默认逐字保留正文、标题、数据和术语，保留顺序、备注和隐藏状态。疑似错字、逻辑重复或更好表达，列“原文→建议→原因”，尚未获授权时不写入。
- 已要求新建、翻译、改写或修正某处时，在该范围内执行，不逐句重复确认；不得编造事实或扩大为整套自由润色。
- 排版规则不自动授权文案变化；长标题或多观点先检查能否在现有内容范围解决。
- 验收：每处变化可追溯到请求；纯排版执行文字/数据对比，已授权改写核对保留项和范围。

### M3 文件结构、逐页视觉和跨页一致性分别验证

- **结构**：核对母版/版式/占位符继承、组合变换、有效字体/颜色、图表/表格及数据关系、备注正文、页序、隐藏状态和媒体。空备注节点不等于有讲稿；文件有视频不等于可播放。
- **逐页**：检查渲染的文字可见边缘、字级、换行、裁切、遮挡、连接语义、图片清晰度与图表读数。
- **跨页**：对照标题/说明位置、主体外框、同类组件内部对齐、字级及色彩角色；特殊页按批准用途验收。
- 工具适配当前环境，不要求固定客户端或Windows脚本。渲染不能代替PowerPoint原生功能或跨设备验证；未做的项目记录MANUAL及原因。
- 适用项记录页码/对象、证据、PASS/FAIL/MANUAL及处理结果；不适用项记N/A。修正授权范围内的问题后交付，不为通过检查改变已批准设计。
- 明确无法验证的实质能力；不凭截图宣称“全可编辑”或“原生检查全部通过”。内部检查记录默认不成为交付文件。

## 维护本规则

更新时同时校准速查、正文和入口，消除相反要求，不只在文末追加例外。新经验先判断适用范围；具体Deck数值放可选参考配置，业务数据、客户材料和内部资源链接不写入通用技能。
