# 量化参考配置：16∶9白底蓝青方案型演示

本配置来自用户手动定稿的重复做法，仅保存可复用的版式与制作参数，不含客户数据、内部链接或原始演示文件。它是规则集C2的参考资料，不是第二套通用规则。

## 何时使用

- 明确要求沿用该风格，或当前模板与此配置一致时，可作测量与复用起点；当前模板实测优先。
- 其他比例、品牌、语言、展示场景需重新校准，不能看到“PPT”就自动采用。仅照参数绘制，不能声称继承了原母版。
- 保留封面、视频、结束页和技术附录的特殊构图，不强制它们套常规主体高度。

## 视觉与对象参数

- 色彩角色参考：品牌蓝`#1F5EFF`、青色`#06B6D4`、深色文字`#12234A`、说明灰蓝`#5A6B8C`、分类橙色`#ED7D31`；重点块用蓝青渐变。现稿存在相邻色值，新增对象选已确认角色色；是否整理原稿色值按任务的配色授权范围执行。
- 普通卡片多用浅底/白底、细描边、克制阴影；重点块按语义选择位置，不固定强调第三列。多类别页面可使用分类色。
- 两类重复卡片的普通圆角半径均约3.2 mm：短边9.78 cm、adj≈0.0327；短边4.62 cm、adj≈0.0701。按实际尺寸与角色复用视觉半径，不把3.2 mm推广到药丸、小标签或所有模板。
- 对齐类文本框通常四边内边距归零；复杂卡片由背景与多层文字构成，通过相对位置建立内留白，简单标签可形文一体。
- 不同高度短标题可保持相同垂直中心；并列卡片同时对齐标题、说明、指标和分隔线，必要时补偿引号或图标透明边缘。
- 手动语义断行参与设计，保留与字级相容的行数；不只因文本框标称宽度不足就判溢出。
