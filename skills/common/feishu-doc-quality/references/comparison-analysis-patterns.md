# 对比分析文档格式参考

本文档收录两种高频复用的对比分析表格格式，用于策略文档、市场分析、方案设计等场景。

---

## 格式一：「差异维度」四列对比表

适用于对比两个对象（国内 vs 海外、产品 A vs 产品 B、现状 vs 目标）的差异，并要求每项差异落实为行动/影响。

### 表头

| 差异维度 | 对象A特点 | 对象B特点 | 对产品/策略的影响 |

### 设计原则

- **差异维度**：选 4-9 个核心维度，每个维度独立、可操作。不宜超过 10 个（决策层阅读负担）。
- **对象特点列**：写"是什么"，不写"怎么办"。
- **影响列**：必须从特点推导出具体的产品/策略影响，而非泛泛而谈。每条影响应是可执行的。
- **排序**：按重要性从高到低排列。最重要的维度放在第一行。

### 已验证的维度集合（海外 vs 国内 AI 客服产品）

| 维度 | 说明 |
|------|------|
| 数据合规与数据主权 | 合规标准、数据驻留、PII 处理 |
| 主流客户触达渠道 | IM/社媒/邮件渠道差异 |
| 采购决策与商业模式 | 决策链长度、SLA、签约模式 |
| 系统集成生态 | 需对接的第三方系统（CRM/工单等） |
| 多语言与本地化深度 | ASR/TTS/NLU 语言能力、本地化适配 |
| 对话文化与消费者预期 | 对话风格、情感表达、投诉文化 |
| 服务与支持模式 | 时区、语言支持、SLA 承诺 |
| AI 治理与可解释性 | 监管要求、可解释性、人在环路 |
| 品牌信任与市场进入壁垒 | 案例资产、信任建设周期、GTM 路径 |

## 格式二：候选市场多维分析表

适用于多市场/多方案/多选项的横向对比，六个维度覆盖从宏观到操作的完整决策链。

### 表头（6 维度）

| 维度 | 覆盖内容 |
|------|---------|
| 市场基本盘 | 人口、互联网渗透率、主要语言、行业规模、坐席成本 |
| 需求与场景 | AI 接受度、最刚需场景、增量 vs 存量替代 |
| 客户画像与决策链 | 采购决策者、决策链复杂度、采购周期、对中国供应商接受度 |
| 竞争格局 | 国际/本地/中国玩家、竞争强度 |
| 监管与合规 | 数据驻留、隐私法规、AI 语音限制 |
| 初步判断 | 最大进入壁垒、最可能切入点、优先级、策略建议 |

### Excel 输出规范

当用户要求"输出为 Excel"时：

- 每个维度大组一个 Sheet（如"市场基本盘""需求与场景"等），方便分屏对比
- 额外加一个"总览对比"Sheet，浓缩所有维度关键数据到一页（适合截图放入文档）
- 用渐变绿色标注优先级（绿=高→黄=中→红=低）
- **不需要置信度/数据来源列**——仅当用户要求时保留，对比表格中移除以减少视觉噪音
- 首行冻结，所有单元格自动换行、垂直顶端对齐
- 使用 `openpyxl` 库，样式用 `PatternFill` / `Font` / `Alignment` / `Border`

### "一句话总结"模式

在综合分析末尾，为每个选项提供一个 30 字以内的一句话画像，格式：

```
| 选项 | 一句话画像 |
|------|-----------|
| A    | 核心特征 + 建议策略——**关键词1，关键词2** |
```

例如：
- 新加坡 | 高门槛、高客单价、高辐射效应的战略门户——**攻标杆，赚品牌**
- 印尼 | 大体量、价格敏感、AI 接受度高——**铺规模，赚体量**

### 注意事项

- 数据必须标注来源和时效性（如 "CNNIC 第57次报告，2025.12"），不确定的数据标"【待验证】"
- 市场分析中，"互联网渗透率"不是孤立数据点——要和 AI 接受度、渠道偏好交叉解读
- 竞争分析要区分"国际大厂""本地玩家""中国出海同行"三层，不能混为一谈
