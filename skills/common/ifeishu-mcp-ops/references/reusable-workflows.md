# 从 Lark 公有云技能保留的经验

本次阅读本机 Lark 技能的入口、相关字段/链接/时间规则后重新提炼；不复制其命令、权限清单、API 能力承诺或对其他 lark-* 的依赖。来源入口清单保留在本次本地整理记录，旧包留恢复备份。

| 来源 | 保留到私有云流程的内容 | 落点 |
| --- | --- | --- |
| lark-base | 资源先解析；record_id 是稳定对象 ID、展示字段不唯一；字段类型先读、Lookup/公式只读、分页和批量逐项检查 | CRM、货架及 MCP 参考 |
| lark-doc / lark-drive / lark-wiki | 分清包装节点和真实目标、Docx 正文与存储文件；用返回 URL，不猜 token；先读后改、回读验证 | 云文档、货架、平台兼容 |
| lark-sheets | 用 sheet_id 而非工作表名；二维区域值、写入计数与回读 | 平台兼容 |
| lark-task / lark-calendar | 明确任务/审批/会议语义；时间换算显式指定用户时区；不依赖容器默认时区 | CRM 日期及下述通用约束 |
| lark-contact / lark-shared | 人员与身份命名空间不能混用；scope、资源权限、身份错误分别处理 | CRM、架构、平台错误解释 |
| lark-markdown | 云空间 .md 与在线文档不同；永久权限/参数错误不盲目重试 | 云文档、平台兼容 |
| lark-openapi-explorer | 先确认现有能力不足，再在独立维护任务中依据原始接口文档补能力 | MCP 维护边界 |
| lark-conventions | 先读后改、同一终稿增量维护、创建位置、返回真实链接 | 云文档；剔除默认 IM 通知与 CLI 入口 |

分页必须依实际 has_more/page_token 继续或明确结果不完整；页大小以当前工具约束为准。写入只改目标字段，先排除重复，再处理部分失败。日期计算采用用户时区与目标字段的秒/毫秒单位，人员 ID 采用目标应用命名空间。

## 没有迁入的内容

审批、考勤、邮箱、OKR、会议/妙记/机器人真实入会、实时事件、妙搭、白板、公有云原生 Slides，以及日程/会议汇总工作流所依赖的公有云命令没有在当前私有 MCP 中得到相应确认。保留一般的“完整分页、区分权限与暂态错误”等经验，不制造替代工具或声称新增能力。

这些公有云 Skill 的活动副本和登记在内容提炼完成后删除，不保留会与私有云入口竞争的自动加载项；以后确需公有云时单独安装隔离环境。
