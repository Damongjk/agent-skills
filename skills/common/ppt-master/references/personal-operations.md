# 原文件操作与品牌参考

整合来源：旧 pptx-ops、iflytek-pptx 中通用经验。未迁入原示例的未定义重排变量、空引用集合删除代码或客户项目文案。

## 编辑已有 PPTX

- 先备份。文件已在 WPS/PowerPoint 中打开时保存到新路径，避免文件锁或编辑器把旧预览回写。不要擅自终止用户应用。
- 尽量从原始副本一次完成当前改动，减少反复拆包重组。若需要重排，依据 presentation.xml 的 r:id 与 presentation.xml.rels 对应关系处理；不能把 r:id 当幻灯片文件名。
- 不使用“收集引用尚未实现、先删所有未引用文件”的示例。没有完整关系图和内容类型验证时，不删除看似孤立的 OOXML 部件。
- ZIP 项名不应重复；关系目标、Content_Types、页面顺序、备注与媒体须检查。只验证页数不能证明文件正确或视觉保真。
- 当前技能整理不自动安装依赖，也不执行 Windows COM；环境依赖按已有解释器与客户端能力选择。

## 从 Office 素材取得架构内容

DOCX/XLSX 仅抽取文本可能遗漏嵌入图片。检查包内 media 和关联关系，按需要提取并查看架构图；保留箭头、分组、拓扑语义。不要因看不到文本就认定没有图。

## 可选浅色品牌基线

没有明确模板时，可采用白/浅灰背景、深色正文和蓝色主强调：背景 `#FFFFFF/#F8F9FB`，正文 `#1F2937/#4B5563`，主色 `#1A56DB`。这是一组备选值，不覆盖用户品牌模板，不要求一次使用多种强调色。客户或云厂商专属配色只在该任务明确涉及并提供依据时使用。

圆角通过 python-pptx 设 `shape.adjustments[0] = 0.08`；对应 XML `val 8000`。卡片文字优先内嵌同一形状，并保留容器留白；不沿用旧辅助函数中微小字号和拆开的“色块+文本框”结构。字体与尺寸遵循 ppt-layout-spec，并检查目标设备字体替换。
